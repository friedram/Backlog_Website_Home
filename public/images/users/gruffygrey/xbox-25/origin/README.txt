YOUR ORIGIN - choose your own images
====================================
Drop a picture in this folder and push to GitHub. The Xbox 25 page picks it
up automatically on the next build - no code changes needed.

  left.png   (or .jpg .jpeg .webp .svg .gif)  - shown next to "Xbox Player Since"
  right.png  (or .jpg .jpeg .webp .svg .gif)  - shown next to "Your First Console"

  full.png   (or .jpg .jpeg .webp .svg .gif)  - ONE wide picture that replaces the whole
                                                graphic (left/right are then ignored)

Tips
- Transparent PNG or WebP looks best (the connector line passes behind it).
- Roughly square (left) or wide (right) images work; they display about
  96px tall, so 400-600px on the long side is plenty.
- Delete the file to go back to the page's built-in default.
